# @hexcuit/discord-bot

[![CI](https://github.com/hexcuit/discord-bot/actions/workflows/ci.yml/badge.svg)](https://github.com/hexcuit/discord-bot/actions/workflows/ci.yml)

League of Legends カスタムマッチの参加管理・チーム分け・レーティング追跡を行うDiscord Botです。

## 機能

- **キュー管理** - カスタムマッチへの参加/離脱
- **チーム分け** - ランダムまたはレーティングベースのバランス調整
- **ランキング** - プレイヤーのレーティングと戦績表示
- **統計** - 個人の成績確認

## インストール

```bash
bun install
```

## 実行

```bash
bun run dev
```
